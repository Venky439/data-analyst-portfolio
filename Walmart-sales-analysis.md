# Walmart Sales Analysis

## Objective
In this project, I worked on Walmart sales data to understand how sales are changing over time and across different stores.

## Tools Used
- Excel
- Power Query

## What I Did
- Imported the dataset into Excel
- Used Power Query to clean and transform the data
- Created pivot tables for analysis
- Built an interactive dashboard using charts and slicers

## Automation
I used Power Query to automate the data cleaning process.  
So when new data is added or updated, the dashboard will automatically refresh without doing all steps again.

## Key Insights
- Some stores are performing better compared to others
- Sales trends change based on time and conditions
- Temperature and fuel price also show some impact on sales
